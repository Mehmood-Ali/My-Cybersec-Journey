# Cybersecurity Tools Notes

This folder contains my **personal notes and references** on various cybersecurity tools.  
The purpose of these notes is to **build my own knowledge base** for both offensive and defensive security practices.

---

## 📂 Structure

Each tool will have its own dedicated folder or file, containing:
- **Installation steps**
- **Basic usage and commands**
- **Practical lab exercises**
- **Common troubleshooting tips**
- **Reference links** for deeper learning

---

## 🧰 Planned Tools

- **Metasploit** – Exploitation and penetration testing framework  
- **John the Ripper** – Password auditing and cracking  
- **Wireshark** – Network packet analysis  
- **Nmap** – Network discovery and port scanning  
- **Burp Suite** – Web application security testing  
- **Hashcat** – Password cracking with GPU acceleration  
- **Sysinternals Tools** – Windows forensics and monitoring  
- **Splunk / ELK Stack** – Log management and analysis  

*(More tools will be added as I expand my lab environment.)*
