To enable a Microsoft Defender for Cloud (CWPP) plan like Defender for Servers, sign in to the Azure portal, navigate to Defender for Cloud, select Environment settings, choose your target subscription, and then toggle the desired Defender plan to On on the Defender plans page. You may need to select a specific plan (Plan 1 or Plan 2) and click Save to complete the process. 
Here's a step-by-step guide for enabling Defender for Servers:

Sign in to the Azure portal . 

Search: for and select Microsoft Defender for Cloud. 

In the Defender for Cloud menu, select Environment settings. 

Select the relevant Azure subscription, AWS account, or GCP project.

On the Defender plans page, find the desired plan (e.g., Defender for Servers) and toggle the switch to On. 

If presented with a choice, select the plan version (e.g., Plan 1 or Plan 2) and click Confirm.

Select Save to apply the changes. 

After Enabling a Plan 

A 30-day trial period may begin.

For Defender for Servers, the Microsoft Defender for Endpoint extension and Microsoft Defender Vulnerability Management are automatically installed on supported machines.

You can then configure specific features of the plan to suit your environment.
