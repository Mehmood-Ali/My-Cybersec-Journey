To review a resource's health in Microsoft Defender for Cloud, navigate to the Azure portal, select Microsoft Defender for Cloud, and then choose Inventory. From the inventory, find your specific resource and select it to open the Resource health page, which provides details on applied security features, outstanding recommendations, and relevant security alerts for that resource. 
Step-by-step guide
Sign in to the Azure portal: Open your web browser and go to portal.azure.com. 
Select Microsoft Defender for Cloud: In the search bar, type "Microsoft Defender for Cloud" and select it from the results. 
Go to the Inventory: In the Defender for Cloud left pane, select Inventory.

Find your resource: Use the "Filter by name" box or other filters to locate the specific resource you want to review. 
Select the resource: Click on the name of the resource in the inventory list. 
Review the Resource Health page: The resource health page will open, displaying information about the resource's security posture, including:
Resource Information: Details about the resource. 
Applied Security Features: Information about the security features in place. 
Recommendations: A list of active security recommendations. 
Alerts: A list of security alerts related to the resource. 
Additional tips
Use Azure Resource Graph (ARG): The inventory utilizes Azure Resource Graph, allowing for deep, custom insights using KQL queries for more detailed analysis. 
Check Secure Score: The Security posture page in Defender for Cloud also shows information about unhealthy resources and relevant recommendations affecting your secure score. 
DevOps Resources: For DevOps resources, you can view their health by selecting them from the DevOps inventory table
