# Task 6 - Review attribute mappings
In this Task you will review the attribute mappings and make sure that the synchronized users will show up in Contoso's global address list.

You should still be logged into the Entra ID portal https://entra.microsoft.com in the Users and groups settings of your cross-tenant synchronization configuration. If not follow these 2 steps to get back to the configuration page:
On the left navigation pane, navigate to Identity > External Identities > Cross-tenant synchronization > Configurations.
Select Contoso cross-tenant synchronization.
Navigate to Provisioning and expand the Mappings section.
Select Provision Microsoft Entra ID Users.
Under the showInAddressList attribute select Edit.
Make sure its Mapping type is set to Constant and its value is set to true.
Select Ok.
Under the displayName attribute select Edit.
Change the Mapping type to Expression.
Remove the preexisting expression.
Select Use the expression builder.
Select the function Append.
In the Select attributed field, select the [displayName] attribute from the drop-down list.
In the Enter suffix field, enter (Contoso) including the space in front of the bracket but without the quotation marks.
Select Add expression. Your expression on the right should look like Append([displayName], " (Contoso)")
You can test your expression by selecting a user.
Select Apply expression and select Ok to leave the edit dialog.
Select Save.
Close the Attribute Mapping page by selecting the X in the top right corner.
You have now made sure, that all synchronized users will show up in the other tenant's global address list. You also have added a (Contoso) expression to the display name of every synchronized user within the other tenant.
