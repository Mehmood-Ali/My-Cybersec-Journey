# SC-200 Lab Folder

This folder contains all of my **hands-on lab materials** for the SC-200: Microsoft Security Operations Analyst certification.  
It is intended to serve as a **reference repository** for all practical exercises, screenshots, exported files, and any notes I create while practicing in my lab environment.

---

## 📂 Contents

- **Screenshots**  
  Images captured during lab exercises, such as:
  - Onboarding devices to Microsoft Defender for Endpoint  
  - Creating and monitoring alerts  
  - KQL query tests in Microsoft Sentinel  
  - Investigating incidents and alerts  

- **Notes / Exports**  
  Any textual notes, exported logs, CSVs, or JSON files that support lab activities.

- **Other Artifacts**  
  Configuration files, scripts, or any other material generated during labs that help document or reproduce the exercises.

---

## 🧪 Lab Environment

- **Virtual Machines**
  - Windows 10 VM – onboarded to Defender for Endpoint  
  - Windows Server 2022 VM – onboarded to Defender for Endpoint  

- **Integrated Services**
  - Microsoft Defender for Endpoint  
  - Microsoft 365 Defender Portal  
  - Microsoft Sentinel connected to the lab environment  

This setup allows me to **simulate a realistic SOC environment**, generate alerts, and practice monitoring, hunting, and incident response.

---

## 📌 Purpose

- To **document all lab exercises** for SC-200 preparation  
- To **retain screenshots** of key steps and results for reference  
- To **store exported files and scripts** that support learning  
- To **maintain an organized record** of practical work for future use
