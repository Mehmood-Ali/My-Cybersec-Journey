## Introduction
The **E-Commerce Mobile Application** is developed to provide customers with a convenient, secure, and efficient platform for buying and selling products online.  

Unlike traditional shopping, which consumes time, effort, and travel costs, this application enables customers to browse products, add them to cart, purchase securely, and review products from the comfort of their homes.  

The app provides a **multi-interface system** including:
- **Admin panel** for managing data and products,  
- **Seller/reseller interface** to list and manage products,  
- **Customer interface** for purchases,  
- **Guest user interface** for browsing products.  

The project was developed for **O7 Services**, following an **Agile methodology** with iterative development and testing.

---

## Features
- User authentication (login, signup).  
- Browsing products with categories and details.  
- Add to cart, wallet balance, and secure checkout.  
- Product reviews and ratings.  
- Chatbot functionality for customer-seller interaction.  
- Admin dashboard for product, user, and reseller management.  
- Cross-platform support (Android + iOS).  

---

## System Components
- **Frontend**: Mobile UI (Android/iOS).  
- **Backend**: Application server handling authentication, product management, and order processing.  
- **Database**: Stores user profiles, products, transactions, and reviews.  
- **Payment Gateway**: Secure financial transactions.  
- **Chatbot**: Customer and seller communication.  

---

## User Roles
- **Admin**: Manages products, categories, users, resellers, and overall sales.  
- **Reseller**: Registers, manages stock, views orders, and earns discounts.  
- **Customer**: Registers, purchases products, checks wallet balance, views orders, and writes reviews.  
- **Guest User**: Can browse and view products but cannot checkout.  

---

## User Stories
- *As an admin*, I must be able to login, manage products, categories, users, and view sales.  
- *As a reseller*, I must be able to register, manage stock, and purchase products.  
- *As a customer*, I must be able to login, browse, purchase, check wallet balance, and review products.  
- *As a guest user*, I must be able to view products and categories but not make purchases.

## Development Approach
- **Methodology**: Agile (iterative development).  
- **Process**: System planning → Requirement specification → Design → Coding → Unit testing → Acceptance testing → Implementation.  
- Weekly stand-ups, Zoom/Google Meet meetings, and status updates ensured progress.  
- Proper testing after each iteration to meet acceptance criteria.
