## 📑 Projects

### 1. [Application of MFCCs in Speech Recognition](./Application%20of%20MFCCs%20in%20Speech%20Recognition/)
- Researched the use of **Mel-Frequency Cepstral Coefficients (MFCCs)** for feature extraction in speech recognition.  
- Implemented in **MATLAB Simulink**, including audio input, framing, FFT, Mel filter banks, log scaling, and DCT.  
- Evaluated performance using **spectrum analyzers**.
