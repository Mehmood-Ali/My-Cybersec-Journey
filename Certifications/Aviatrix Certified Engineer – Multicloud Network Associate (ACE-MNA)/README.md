## 📘 About the Certification
The ACE-MNA certification validates foundational knowledge of **multicloud networking** using Aviatrix.  
It focuses on designing, building, and securing networks across AWS, Azure, GCP, and OCI.  

This certification is a stepping stone for deeper Aviatrix and cloud networking certifications.

---

## ✅ Exam Topics
- Cloud Networking Basics (VPCs, VNets, Subnets)  
- Multicloud Networking Overview  
- Aviatrix Architecture & Components (Controller, Gateways)  
- Deploying Aviatrix Controller and Gateways  
- Secure Connectivity (VPN, Encryption, Peering)  
- High Availability & Redundancy Across Clouds  
- Day-2 Operations & Monitoring with Aviatrix  
- Security & Compliance in Multicloud Networking
