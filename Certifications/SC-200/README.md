# SC-200: Microsoft Security Operations Analyst

This folder contains my **study notes, labs, and resources** for the SC-200 certification.  
The goal is to maintain a structured knowledge base that I can refer to while studying and during practical lab work.

---

## 📂 Folder Structure

- **notes/**  
  Detailed theory and concept notes for each SC-200 topic.
  
- **labs/**  
  Screenshots, configurations, and evidence from lab exercises, including:
  - Microsoft Defender for Endpoint
  - Microsoft Sentinel
  - KQL (Kusto Query Language) practice queries

- **queries/**  
  Useful KQL queries for incident detection, investigation, and hunting.

- **practice/**  
  Links, practice questions, and mock exam notes.
