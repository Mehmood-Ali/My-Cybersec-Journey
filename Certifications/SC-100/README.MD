## 📘 About SC-100
The SC-100 exam tests your ability to design and evolve a cybersecurity strategy that protects an organization's mission and business processes.  
It covers advanced skills in governance, security operations, and technical strategy across Microsoft and hybrid environments.

## ✅ SC-100 Exam Skills Outline

Here’s what I need to cover for SC-100, based on Microsoft’s official exam guide:

### 1. Design a Zero Trust strategy and architecture (25–30%)
- Define business requirements for Zero Trust
- Design identity and access strategy
- Design device and endpoint strategy
- Design network and infrastructure strategy
- Design applications and workload strategy
- Design data security strategy

### 2. Evaluate governance risk compliance (GRC) technical strategies and security operations strategies (20–25%)
- Recommend logging and auditing strategies
- Recommend regulatory compliance strategies
- Recommend identity governance strategies
- Recommend insider risk strategies

### 3. Design security for infrastructure (20–25%)
- Secure cloud, hybrid, and on-premises infrastructure
- Recommend security for different workloads (VMs, containers, serverless, etc.)
- Design security for network segmentation and access

### 4. Design a strategy for securing data and applications (20–25%)
- Recommend security for structured/unstructured data
- Design encryption and key management strategies
- Recommend application security strategies
- Integrate DevSecOps practices
